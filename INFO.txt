└────────────────────────────────────────────────────────────────┘

      cd backend && npm install && cd ..
      cd frontend && npm install && cd ..

  2️⃣  Iniciar o sistema:

      ./start.sh

  3️⃣  Acessar no navegador:

      http://localhost:5173

┌────────────────────────────────────────────────────────────────┐
│  💡 DICAS                                                      │
└────────────────────────────────────────────────────────────────┘

  • Mantenha registros diários consistentes
  • Fotografe sempre do mesmo ângulo
  • Faça backups semanalmente (./backup.sh)
  • VPD é mais importante que temp/umidade separadas
  • Aumente PPFD gradualmente conforme crescimento

┌────────────────────────────────────────────────────────────────┐

  Umidade:      50-70%
  VPD (veg):    0.8-1.2 kPa
  VPD (flor):   1.0-1.5 kPa
  PPFD (veg):   400-600 μmol/m²/s
  PPFD (flor):  600-900 μmol/m²/s
