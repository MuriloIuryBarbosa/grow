## 🚀 Como Usar

### 1️⃣ Primeira Vez - Instalação

```bash
# Instalar dependências do backend
cd backend
npm install
cd ..

# Instalar dependências do frontend
cd frontend
npm install
cd ..
```

### 2️⃣ Iniciar o Sistema

```bash
# Forma automática (recomendada)
./start.sh

# OU manualmente em dois terminais

# Terminal 1 - Backend
cd backend && npm run dev

# Terminal 2 - Frontend  
cd frontend && npm run dev
```

### 3️⃣ Acessar

Abra seu navegador em: **http://localhost:5173**

## 🎯 Fluxo de Uso

1. **Cadastrar Planta**
   - Clique em "+ Nova Planta"
   - Preencha os dados
   - Adicione foto (opcional)
   - Salve

2. **Acompanhar Diariamente**
   - Clique na planta
   - Clique em "+ Novo Registro"
   - Preencha dados do dia
   - Adicione foto
   - Salve

3. **Atualizar Fase**
   - Na página da planta
   - Clique no botão da nova fase
   - Atualizará automaticamente

4. **Ver Análises**
   - Clique em "📊 Análises"
   - Veja estatísticas gerais
   - Veja alertas e recomendações

## 💾 Backup dos Dados

```bash
./backup.sh
```

Cria backup automático de:
- Banco de dados (grow.db)
- Todas as fotos (uploads/)

Backups ficam em `backups/YYYYMMDD_HHMMSS/`
