# ShuriGrow - Identidade Visual

## Cores da Marca

| Nome | Hex | Uso |
|------|-----|-----|
| Verde Principal | `#2E7D32` | Fundo do ícone, elementos principais |
| Verde Claro | `#4CAF50` | Botões, destaques |
| Verde Folha | `#81C784` | Elementos secundários |
| Verde Suave | `#C8E6C9` | Fundos claros |
| Marrom Tronco | `#795548` | Elementos de terra/planta |
| Marrom Escuro | `#5D4037` | Sombras, solo |

## Arquivos de Ícone

- `icon.svg` - Ícone vetorial original (1024x1024)
- Converter para PNG usando: https://cloudconvert.com/svg-to-png

## Tamanhos Necessários

### Android
- `icon.png` - 1024x1024 (ícone principal)
- `adaptive-icon.png` - 1024x1024 (ícone adaptativo foreground)

### iOS
- `icon.png` - 1024x1024

### Splash Screen
- `splash-icon.png` - 1284x2778 (ou usar o ícone centralizado)

## Como Gerar os PNGs

1. Acesse https://cloudconvert.com/svg-to-png
2. Upload do `icon.svg`
3. Configure para 1024x1024
4. Baixe e coloque em `mobile/assets/`

## Fontes Recomendadas

- **Títulos**: Poppins Bold
- **Corpo**: Inter Regular
- **Números**: Roboto Mono

## Conceito do Ícone

O ícone representa:
- 🌱 Uma planta em crescimento (core do app)
- 📈 Seta de crescimento (tracking de progresso)
- ✨ Pontos de brilho (vitalidade e saúde)
- 🪴 Vaso (cultivo indoor)
